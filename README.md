# OOP Coursework — Online Store Backend

Курсова робота з дисципліни «Об’єктно-орієнтоване програмування».

**Тема:** «Розробка серверної частини інформаційної системи інтернет-магазину»

**Студентка:** Владислава Гунія, АІ-244

## Опис проєкту

Проєкт являє собою серверну частину інформаційної системи інтернет-магазину, реалізовану на Java та Spring Boot.

Застосунок побудований за багатошаровою архітектурою:

Controller → Service → Repository → Database

Основні сутності системи:
- Product
- Category
- Customer
- Order
- OrderItem

## Технології

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- Jakarta Bean Validation
- Postman

## Основні можливості

- CRUD-операції для основних сутностей
- створення товарів, категорій, клієнтів та замовлень
- пошук товарів
- отримання товарів за категоріями
- аналітичні запити
- валідація вхідних даних
- обробка помилок REST API
- збереження даних у PostgreSQL

## Налаштування бази даних

Застосунок використовує PostgreSQL.

Необхідно створити базу даних:

`labwork2`

Пароль до PostgreSQL передається через змінну середовища:

`DB_PASSWORD`

## Запуск

1. Створити базу даних `labwork2`.
2. Встановити змінну середовища `DB_PASSWORD`.
3. Запустити `Labwork2Application`.
4. Сервер працюватиме на:

`http://localhost:8080`

## Тестування API

Для перевірки REST API використовується Postman.

У репозиторії міститься Postman Collection:

`lab2-ai-244-guniya.postman_collection.json`

За її допомогою можна перевірити основні CRUD-операції, пошук, аналітичні запити, валідацію та обробку помилок.
